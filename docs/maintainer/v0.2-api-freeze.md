# v0.2.0 public-API freeze audit

Entered: 2026-10-03  
Feature-freeze commit: `3bcc5076ff59827583727da8a751722d2dbb45a9`  
Release branch: `release/0.2`

This record captures the public-surface audit performed before the immutable
`freeze/api-0.2.0` checkpoint is created.

## Scope

v0.2.0 is in feature freeze. The committed release scope is:

- packed encoded-sRGB storage through `SRgb8`;
- packed encoded-sRGB straight-alpha storage through `SRgba8`;
- explicit checked storage/computational conversion;
- exact compact `#RRGGBB` / `#RRGGBBAA` interop;
- sRGB OKLCH chroma-boundary measurement;
- CIE Lab D50 conversion and Delta E 76 / CIEDE2000 measurement;
- model-specific CVD transformations and prepared/batch CVD application;
- the already released v0.1 mathematical core.

HSL/HSV, wider-gamut spaces, general CSS Color parsing, and application theme
policy remain outside the frozen v0.2.0 feature scope.

## Audit corrections

The audit found evidence/documentation drift rather than a required API
redesign:

1. root/direct-module compile probes did not yet exercise all promoted
   CIELAB/Delta-E/gamut-boundary/storage declarations;
2. the named-argument probe did not cover the new v0.2 callables;
3. README, documentation index, compiler-matrix wording, and CHANGELOG still
   contained stale v0.1.1-as-current-work wording even though v0.1.1 had
   already been published;
4. release-line pull requests were not covered by the normal PR CI triggers;
5. manual compiler-matrix runs always checked out `develop`, making them
   unsuitable for release-branch qualification.

The audit fixes those release-engineering gaps without intentionally changing
public numerical behavior or the accepted public API.

## Supported compiler contract

v0.2.0 is qualified against:

- DMD 2.112.1;
- DMD 2.113.0;
- LDC 1.42.0;
- LDC 1.43.0;

on Ubuntu 24.04 x86-64.

Fast CI uses DMD 2.113.0 and LDC 1.43.0. The full supported matrix is a release
qualification gate. DMD 2.111.0 and LDC 1.41.0 remain diagnostic canaries, not
supported release compilers.

validation are green. After that checkpoint, implementation, tests, comments,
documentation, CI, packaging, and release qualification may continue only
